Coinbase QA Automation Suite — JavaScript / Playwright Edition


I created a test automation framework built with JavaScript and Playwright Page Object Model (POM), targeting the Coinbase web application. This repository is a direct port of an equivalent Python/Selenium framework, created to demonstrate the ability to translate a proven QA automation architecture into a different language and tooling ecosystem quickly and correctly.

Companion repository: python_harness-h (https://github.com/agrant23/python_harness-h)

Why This Repository Exists
My  automation background is in Python and C# with Selenium. This repository was built to demonstrate that I quickly pick up other scripting languages.

I converted the original Python/Selenium framework into this JavaScript/Playwright version in approximately 6 hours, without prior professional experience in either JavaScript or Playwright. The goal wasn't to become a JavaScript expert overnight — it was to prove that I can pick up an unfamiliar language and framework fast enough to be productive on a team using it from day one.
In short: if a role requires JavaScript/Playwright, I can hit the ground running.
